# SMTP設定

SMTP設定はスーパーユーザーだけが変更できます。ホスト、ポート、STARTTLS／TLS接続／暗号化なし、SMTP認証、ユーザー名、パスワード、From、Reply-To、Envelope-From、タイムアウトを設定します。

接続テストはDNS・TCP接続・バナー・EHLO・TLS・証明書検証・認証・QUITを確認し、メールは送信しません。テストメールはログイン中スーパーユーザーの確認済みメール1件だけへ送信します。

TLS証明書はpeerとホスト名を検証し、自己署名証明書を許可しません。パスワード、AUTH文字列、SMTP通信全文は画面や監査ログへ記録しません。
