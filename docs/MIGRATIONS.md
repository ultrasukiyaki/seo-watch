# DBマイグレーション

起動時に `schema_migrations` を確認し、一意ID、SHA-256 checksum、状態、適用日時、アプリバージョンを記録します。v0.9.0以前の環境は、既存テーブルを削除・再作成せず `baseline_v0.9.0` として登録します。

適用済みは再実行せず、checksum不一致やrunning状態を検出した場合は安全停止します。失敗時は秘密情報を含まない要約だけを保存します。更新前には必ずDBバックアップを取得してください。

## v0.10系の記録

- `baseline_v0.9.0`: マイグレーション履歴導入前の既存環境を、データ変更なしで基準化
- `20260724_001_v010`: 改善タスク、履歴、同期lease、同期履歴拡張

マイグレーション全体はMySQL advisory lockで同時実行を防ぎ、個別DDLは `CREATE TABLE IF NOT EXISTS` と列・索引の存在確認により冪等化しています。適用済みSQLを書き換えてchecksum不一致にしないでください。
