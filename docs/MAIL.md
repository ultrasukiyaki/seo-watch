# メール配送

v0.11.0では、設定画面から「使用しない」「PHP mail()」「SMTP」を選択できます。既定は「使用しない」です。

PHP mail()の成功はPHPがメッセージを受け付けたことだけを示し、宛先への到達を保証しません。運用環境では、証明書検証を有効にしたSMTPを推奨します。

スーパーユーザーのメールは任意です。配送無効時にも確認待ちとして保存でき、配送設定後にアカウント画面から確認メールを送信できます。確認済みになるまで、パスワード再設定や通知には利用しません。

SMTPパスワードは`config/local.php`へ保存せず、APPキーを用いたAES-256-GCM暗号文としてDBへ保存します。APPキーを失うと復号できないため安全にバックアップしてください。

実際のSPF・DKIM・DMARC合否はSMTPサーバーとDNS設定によって決まります。SEO Watchは配送認証の合格を保証せず、DNS変更やDKIM署名は行いません。
